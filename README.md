# Hamza Farooq Portfolio

Modern personal portfolio built with React + Vite, Tailwind CSS, GSAP, Three.js and React Three Fiber.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Main customization points
- `src/App.jsx` — content, sections and links
- `src/components/Scene.jsx` — Three.js hero scene
- `src/index.css` — global styling and visual effects
- `public/hamza.jpg` — profile photo
